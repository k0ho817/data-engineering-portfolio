# DBLAB 데이터 처리 구현 기록

DBLAB 연구용 코드와 실행 메타데이터를 바탕으로 데이터 처리 과정을 정리했다. 공개 저장소에는 처리 설명과 결과 요약을 담았고, 원천 데이터와 내부 설정은 연구실 환경에서 관리한다.

## FineWeb 입력 표준화

`download_fineweb_subset.py`는 스트리밍으로 들어오는 문서를 선별해 Parquet로 저장한다. `tokenize_fineweb_subset.py`는 EOS 토큰을 붙인 뒤 고정 길이로 나누고, 만든 시퀀스 수와 남은 토큰 수를 기록한다.

공유 저장소의 2026-08 메타데이터:

| 항목 | 기록 값 |
| --- | ---: |
| 수집 문서 | 50,000 |
| 생성 시퀀스 | 104,683 |
| 시퀀스 길이 | 512 |
| 출력에서 제외된 잔여 토큰 | 152 |

표의 수치는 2026년 8월 실행 시 저장된 메타데이터에서 가져왔다.

## Spark ImageNet 전처리

`spark/preprocessing.py`의 구현 흐름:

1. binaryFile로 JPEG와 파일 메타데이터 읽기.
2. 경로·파일명에서 synset 추출.
3. distinct·정렬·row_number로 라벨 맵 생성.
4. broadcast join으로 라벨을 결합.
5. 파티셔닝·파티션 내부 정렬·ZSTD Parquet 출력.
6. 이미지 수·라벨 수·바이트 수 요약 작성.

전처리는 PySpark DataFrame API로 작성했다. `512`는 라벨 기준 재분배에 사용한 파티션 설정값이다.

## 센서 데이터

`logToCSV.py`에서 센서 로그를 표 형태로 바꿨다. `trans.ipynb`에서는 시각을 파싱하고 ROI별 데이터를 나눈 뒤 프레임 정보와 조인해 객체 클래스를 변환했다. 좌표 그림은 원본 로그에서 추출한 표본으로 만들었다.

## 벡터 데이터
