목표를 다시 정한 드론 프로젝트

탑다운 카메라로 사람을 탐지하고 드론이 대상을 추적하는 시스템을 만들었습니다. 데이터 부족과 Raspberry Pi의 연산 한계를 확인한 뒤, 처음 세운 목표와 추론 조건을 조정했습니다.

YOLOv8nRoboflowPyTorch DDPRaspberry PiOpenCV

처음 목표와 확인한 제약

처음 목표

드론 하단 카메라로 사람을 찾고 색상을 기준으로 피아를 구분한 뒤, 탐지된 객체를 추적하는 것이었습니다.

현장에서 확인한 문제

  • 탑다운 시점의 사람 데이터 부족
  • Raspberry Pi의 제한된 추론 성능
  • 작은 입력에서 원형 객체 오인
  • 그림자와 조명에 따른 색상 변화

목표와 실행 조건 수정

데이터
Roboflow에서 직접 Bounding Box를 그려 탑다운 사람 데이터셋을 만들고 증강을 적용했습니다.
목표
조명에 민감한 색 기반 피아 구분은 제외하고 사람 객체 탐지에 집중했습니다.
추론
실시간 FPS만 높이기보다 프레임 수를 낮추고 입력 이미지 크기를 키워 작은 사람 객체를 확인했습니다.
학습
RTX 3080 Ti 2장과 DDP로 batch size와 image size 조건을 비교했습니다.

학습 데이터와 조건

28,067train 이미지
1,147validation 이미지
574test 이미지
ModelYOLOv8n
Epoch100
Image size640
Batch size160
HardwareNVIDIA RTX 3080 Ti × 2

이 프로젝트에서 내린 판단

처음 계획보다 실제 입력과 장비 조건을 우선했습니다.색상 기반 구분을 끝까지 유지하는 대신 데이터로 확인 가능한 사람 탐지에 집중했습니다. 추론 속도와 작은 객체 인식 사이에서는 입력 해상도를 유지하고 처리 FPS를 조정했습니다.
